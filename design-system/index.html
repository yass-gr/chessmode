Design system · v0.1

Openings, learned in depth.

Chessmode's interface: a dark, quiet stage where one warm orange marks the move that matters. Tactile buttons with real depth, soft gradients and 3D objects make a free trainer feel like a premium one.

See the screensComponents

Color

Near-black surfaces stepped by lightness, warm-white text, and one orange that only marks the next action, the target square or progress.

Move labels

Chess.com-style names for game review. Each label carries a symbol and a word, so colour is never the only signal.

Typography

Geist for everything you read, Geist Mono for notation and numbers that must line up. Tight tracking on large sizes, normal at body size.

Depth

Every pressable thing has a body. A top highlight, a darker lip underneath and a soft shadow make buttons look like objects; pressing moves them down 2px and the lip shrinks.
