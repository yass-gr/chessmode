# Mascot asset usage

These assets are intended for integration by the app. Coach expressions share a square canvas; choose the expression that fits the message. Result and empty-state illustrations replace the listed images only in the specified contexts, leaving their other uses intact.

| File | Intended use | Existing image replaced |
| --- | --- | --- |
| `static/img/mascot/neutral.webp` | Neutral coach in review and lesson notes | None |
| `static/img/mascot/happy.webp` | Happy coach feedback | None |
| `static/img/mascot/thinking.webp` | Thinking coach or hint | None |
| `static/img/mascot/wince.webp` | Gentle response to a blunder, and an arena loss | `knight.webp` in arena losses |
| `static/img/mascot/celebrating.webp` | Celebratory coach feedback | None |
| `static/img/mascot/encouraging.webp` | Encouraging coach feedback | None |
| `static/img/mascot/full.webp` | Full mascot for general use | None |
| `static/img/icon-192.png` | Installed app icon, 192px | Previous `icon-192.png` |
| `static/img/icon-512.png` | Installed app icon, 512px | Previous `icon-512.png` |
| `static/img/apple-touch-icon.png` | Apple touch icon | Previous `apple-touch-icon.png` |
| `static/favicon.png` | Browser favicon | Previous `favicon.png` |
| `static/img/icon-maskable-512.png` | Maskable installed app icon | None |
| `static/img/result/win.webp` | Arena win result | `node-done.webp` in arena wins |
| `static/img/result/draw.webp` | Arena draw result | `king.webp` in arena draws |
| `static/img/result/quiz.webp` | Chapter quiz result | `king.webp` in quiz results |
| `static/img/result/practice.webp` | Practice result | `node-done.webp` in practice results |
| `static/img/result/timed.webp` | Timed drill result | `flame.webp` in timed results |
| `static/img/result/mistakes.webp` | Mistakes drill result | `node-locked.webp` in mistakes results |
| `static/img/empty/arena.webp` | Arena empty or locked state | `node-locked.webp` in arena state |
| `static/img/empty/drill.webp` | Drill empty or locked state | `node-locked.webp` in drill state |
| `static/img/empty/practice.webp` | Practice empty or locked state | `node-locked.webp` in practice state |
